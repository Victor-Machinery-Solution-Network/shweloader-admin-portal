Design Highlights

Three-Panel Layout
  • Left: Session list with tabs (All | Unread | Active | Resolved)
  • Center: Conversation with inline product cards — both admin and user can share products
  • Right: Context panel — user info + all products discussed + session metadata
Product Messages (inline)
  • Products render as rich cards in the message flow — brand, name, price, type
  • "View Listing →" link opens the listing detail page
  • Both user and admin can share products
  • Admin input bar has a 📦 button to search and share a product
Context Panel (Right)
  • User Info: Name, phone, email, company — always visible
  • Products Discussed: Aggregated from all product messages in the session — clickable cards link to listings
  • Session Info: Status, start date, message count
  • Could later add: user's other sessions, purchase history, notes
