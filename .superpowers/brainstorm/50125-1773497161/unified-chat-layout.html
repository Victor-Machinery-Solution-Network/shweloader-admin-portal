Key Design Decisions

Session List (Left Panel)
  • Tabs: All | Unread | Active | Resolved (with counts)
  • Pending sessions: Amber left border + "NEW" badge for visual distinction
  • Enquiry indicator: Amber dot + listing info (model · For Sale/Rent)
  • General support: No dot, shows "General Support"
  • Selected: Blue left border + light blue background
  • Resolved: Reduced opacity + green "Resolved" badge
  • Unread count: Red circle badge (same as current)
Conversation Panel (Right Panel)
  • Header: User name, status badge, contact info, "Resolve" button
  • Product card: Shows below header for enquiry sessions (listing context)
  • Messages: Grouped by sender, date separators, same bubble style as current
  • Input: Attachment + text + send — same as current ChatInputBar
What's New vs Current
  • ❌ No more separate /enquiries page
  • ❌ No more "Reply" → create session step (sessions exist from creation)
  • ✅ Pending sessions have "NEW" badge for visual distinction
  • ✅ Status: pending → active → resolved (single source of truth)
  • ✅ "Resolve" replaces "Close Session" (better language)
  • ✅ Tabs: All | Unread | Active | Resolved
