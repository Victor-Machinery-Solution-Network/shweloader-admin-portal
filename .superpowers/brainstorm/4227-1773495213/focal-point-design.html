Key Differences from Current

Current (react-easy-crop)
  • Zoom slider (confusing for this use case)
  • objectFit modes cause stretching
  • Container aspect ratio vs crop aspect ratio mismatch
  • Complex focal point math from crop area
  • 30KB+ library dependency
New (custom ~100 lines)
  • No zoom — image scales to fit, drag only
  • No objectFit confusion — plain CSS/math
  • Container always shows full image
  • Simple focal point: dragOffset / overflow
  • Zero dependencies

Component Architecture

FocalPointModal (replaces current)
  ├─ DragArea — full image + crop overlay + drag handler
  ├─ Preview — small live preview at target aspect ratio
  └─ Actions — Reset + Save buttons
