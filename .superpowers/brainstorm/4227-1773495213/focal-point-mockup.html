Design Details
Single-axis drag
Only drags along the axis that overflows. Landscape image in 1:1 crop = horizontal drag only.
Live preview
Small preview at exact target aspect ratio updates in real-time as you drag.
Aspect badge
Shows the target ratio (16:9, 1:1, 4:3) so admin knows what they're framing for.
No zoom
Image auto-scales to fill crop width/height. No slider, no confusion. Just drag.
Rule of thirds
Subtle grid lines help compose the image within the crop area.
Same data format
Outputs identical 0-1 focal point coordinates. Zero changes to DB, API, or RN app.
